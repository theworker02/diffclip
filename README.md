# diffclip

Diff structured JSON clip payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/diffclip/

## Install / run

```bash
git clone https://github.com/theworker02/diffclip.git
cd diffclip
node src/cli.js
node --test
```
